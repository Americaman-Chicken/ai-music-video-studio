# Codex handoff
Goal: Android installable music video PWA, private media, free-first. Read README and app/index.html, app/studio.js, align.py, render.mjs. Preserve existing user media locally; never upload to public repo. No API tokens in app or browser storage. First run browser tests of media loading, IndexedDB, local recording and playback; test 2s fixture and 3min audio on Android. Then implement genuine word-level forced alignment with confidence, section detection using audio features/repetition (do not call loudness alone chorus detection), editable timeline, scene-level prompt parsing and structured output, and shared preview/export rendering. Add regression tests and update SW cache on releases. Prefer private processing and explicit consent for cloud jobs. Do not claim successful deployment without actual evidence. Use existing v3 code as baseline. Deliver incremental commits and verify outputs with ffprobe. Avoid unbounded background work or silent charges.
